# Sandbox Security — JAYA_OS

## Overview

JAYA_OS implements a **capability-based sandbox** for all mounted features. The sandbox ensures that features (whether generated by the brain or user-installed) cannot access system resources beyond their declared permissions.

---

## Security Model

### Principle: Least Privilege
- Features run with **only the permissions they declare**
- No ambient authority — no access to filesystem, network, or hardware by default
- All capabilities must be explicitly granted via manifest

### Capability System

| Capability | Description | Risk Level |
|---|---|---|
| `fs_read` | Read files in allowed directories | Low |
| `fs_write` | Write files in allowed directories | Medium |
| `net_http` | Outbound HTTP requests to vetted domains | High |
| `ui_render` | Mount UI via JayaBridge | Low |
| `ipc_send` | Send IPC messages | Low |
| `memory_read` | Read shared memory | Medium |
| `memory_write` | Write shared memory | Medium |
| `process_spawn` | Spawn child processes | Critical |
| `system_info` | Read system information | Low |

## Capability Enforcement

### Filesystem Proxy
```python
class FilesystemProxy:
    def __init__(self, allowed_read: List[str], allowed_write: List[str]):
        self.allowed_read = [Path(p).resolve() for p in allowed_read]
        self.allowed_write = [Path(p).resolve() for p in allowed_write]
    
    def read(self, path: str) -> str:
        resolved = Path(path).resolve()
        if not any(resolved.is_relative_to(p) for p in self.allowed_read):
            raise PermissionError(f"Read not allowed: {path}")
        return resolved.read_text()
    
    def write(self, path: str, content: str) -> None:
        resolved = Path(path).resolve()
        if not any(resolved.is_relative_to(p) for p in self.allowed_write):
            raise PermissionError(f"Write not allowed: {path}")
        resolved.write_text(content)
```

### Network Proxy
```python
class NetworkProxy:
    def __init__(self, allowed_domains: List[str]):
        self.allowed_domains = allowed_domains
    
    def request(self, method: str, url: str, **kwargs) -> Response:
        parsed = urlparse(url)
        if parsed.netloc not in self.allowed_domains:
            raise PermissionError(f"Domain not allowed: {parsed.netloc}")
        return requests.request(method, url, **kwargs)
```

## Sandbox Lifecycle

```
1. FEATURE MOUNT REQUEST
         │
         ▼
2. VALIDATE MANIFEST
   - Check signature (if signed)
   - Verify permissions are declared
   - Check resource limits
         │
         ▼
3. CREATE SANDBOX CONTEXT
   - Set up import whitelist
   - Block dangerous builtins
   - Configure resource limits
   - Create capability proxies
         │
         ▼
4. LOAD FEATURE MODULE
   - Execute in restricted namespace
   - Inject capability proxies as globals
   - Register with JayaBridge
         │
         ▼
5. FEATURE RUNNING
   - All capability access goes through proxies
   - Resource usage monitored
   - Violations → immediate termination
         │
         ▼
6. FEATURE UNMOUNT
   - Cleanup resources
   - Revoke capabilities
   - Audit log
```

---

## Violation Handling

| Violation | Action |
|---|---|
| Import not whitelisted | `ImportError` raised, feature terminated |
| Blocked builtin called | `SecurityError` raised, feature terminated |
| Filesystem access outside allowed paths | `PermissionError` raised, feature terminated |
| Network request to unallowed domain | `PermissionError` raised, feature terminated |
| CPU limit exceeded | Feature throttled, then terminated if persistent |
| Memory limit exceeded | Feature terminated immediately |
| Execution timeout | Feature terminated |

## Configuration

```python
@dataclass
class SandboxConfig:
    # Import policy
    allowed_imports: List[str] = field(default_factory=lambda: [
        "json", "math", "datetime", "typing",
        "dataclasses", "enum", "collections",
        "itertools", "functools", "hashlib",
        "uuid", "re", "string", "textwrap",
    ])
    blocked_builtins: List[str] = field(default_factory=lambda: [
        "__import__", "eval", "exec", "compile",
        "open", "input", "exit", "quit",
    ])
    
    # Resource limits
    cpu_limit_percent: int = 50
    memory_limit_mb: int = 200
    execution_timeout_sec: int = 30
    
    # Network
    default_allowed_domains: List[str] = field(default_factory=list)
    
    # Filesystem
    default_read_paths: List[str] = field(default_factory=lambda: ["./features", "./data"])
    default_write_paths: List[str] = field(default_factory=lambda: ["./features/tmp"])
```
