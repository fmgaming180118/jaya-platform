# JAYA Agent

JAYA Agent mengorkestrasi tugas dan pemanggilan alat berdasarkan rencana dari
Core. Setiap aksi harus memiliki scope izin, timeout, audit, dan persetujuan
sesuai dampaknya.

**Kematangan:** prototipe; integrasi permission/tool end-to-end belum
diverifikasi sebagai production.
