# Governance

JAYA Research is maintained by the repository owner. Public source visibility
supports review and authorized evaluation; it does not grant contribution,
redistribution, or deployment rights beyond the `LICENSE`.

Research artifacts require provenance, reproducibility information, schema and
license checks, isolated testing, security review, human approval, signed
installation, observability, and rollback before they can affect another JAYA
module.

Boolean caller claims such as `tests_passed=true` are not evidence. Use actual
runner output and retain the command, environment, dataset version, and result.
