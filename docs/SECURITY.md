# Kebijakan Keamanan (Security Policy)

## Keamanan Repositori & Hak Akses
- Repositori ini bersifat **Public (Dapat Dilihat Publik)** untuk tujuan riset dan pembelajaran.
- **Perizinan Write & Push**: Hanya pemilik repositori (`fmgaming180118`) yang memiliki akses langsung untuk mengubah branch utama (`master` / `main`).
- Pengguna eksternal tidak memiliki akses langsung untuk memodifikasi kode. Semua saran atau kontribusi harus melalui *Fork* dan *Pull Request* yang ditinjau secara manual.

## Pelaporan Kerentanan
Jika Anda menemukan masalah keamanan atau kerentanan dalam repositori ini:
1. Jangan membuat Issue publik.
2. Laporkan secara pribadi kepada pemilik repositori via GitHub Security Advisories atau email kontak.
