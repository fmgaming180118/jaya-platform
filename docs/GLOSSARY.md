# Glossary

- **Evidence artifact:** A versioned output containing provenance, payload,
  validation results, and integrity metadata.
- **Research workspace:** Isolated storage for one research session and its
  uploaded or generated material.
- **Promotion:** A reviewed installation of an artifact into another JAYA
  runtime or module.
- **Provider:** An external model, search, speech, or ingestion service.
- **Platform workspace:** The private `jaya-platform` experiment repository,
  which is outside this release.
- **Production:** A release with executable deployment, security, monitoring,
  rollback, and evidence gates, not merely a successful local demo.
