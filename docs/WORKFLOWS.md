# Workflows

## Local research workflow

1. Configure local environment and a unique secret.
2. Start the Research API on loopback.
3. Start the UI and verify the API health endpoint.
4. Ingest authorized material within the configured upload limits.
5. Review evidence and citations before using generated conclusions.
6. Export only approved artifacts.

## Promotion workflow

Research produces an evidence package. Promotion to another JAYA module is a
separate, reviewed operation requiring provenance, validation, isolation,
security review, human approval, signed installation, observability, and
rollback.

No workflow in this repository authorizes unattended self-modification or
unbounded autonomous execution.
