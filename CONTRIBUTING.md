# Kontribusi ke JAYA

JAYA belum menerima kontribusi kode publik, pull request, fork untuk
pengembangan, atau distribusi turunan. Source tersedia hanya berdasarkan
[ketentuan proprietary](LICENSE).

Jangan mengunduh, menjalankan, memodifikasi, atau mengirim ulang bagian proyek
tanpa persetujuan tertulis dari pemilik repository. Issue publik, jika nanti
diaktifkan, hanya boleh digunakan untuk laporan keamanan atau umpan balik yang
tidak menyertakan source turunan.

Kontribusi dapat diterima hanya setelah ada persetujuan tertulis terpisah yang
menjelaskan kepemilikan, kerahasiaan, dan hak penggunaan kontribusi tersebut.
